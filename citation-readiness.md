# Citation Readiness Checklist

- [ ] State one bounded claim at a time.
- [ ] Preserve units, dates, populations and conditions.
- [ ] Link primary evidence where available.
- [ ] Label first-party observations as observations.
- [ ] Separate source facts from interpretation.
- [ ] Keep stable entity names and canonical URLs.
- [ ] Provide enough surrounding context to avoid misleading extraction.
- [ ] Recheck time-sensitive claims before reuse.
