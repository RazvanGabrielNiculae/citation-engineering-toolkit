# Citation Engineering Toolkit

Practical claim-evidence and citation-readiness tools for verifiable web content.

This project is independently usable and intentionally topic-first. It contains working assets rather than a repository created only to multiply links.

## Quick start

The Python utilities use only the standard library. Run the relevant tool against the included synthetic example, then replace the example with your own data or page.
